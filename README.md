A 2.5D action platformer set in a Japanese-fantasy world. Choose a samurai cat clan, master its abilities, and fight increasingly dangerous skeleton armies.

## Portfolio note

This repository contains the packaged Windows build and project documentation. The original Unreal Engine source project is not included, so the repository is intended as a playable portfolio artifact rather than a source-code sample.

## Gameplay

- Choose one of three clans with a distinct combat identity:
  - **Mizushin** — water and ice, focused on magic.
  - **Kagetsu** — fire, focused on strength.
  - **Kazekukan** — wind and earth, focused on agility, speed, and defence.
- Fight with a katana and clan-specific abilities.
- Earn experience and improve strength, agility, and intelligence.
- Face enemies whose statistics scale with progression.
- Continue through an endless level structure designed for long-term character growth.

## Technical highlights

- Built in **Unreal Engine 5** as a 2.5D game.
- Persistent save system.
- Enemy AI and progression-aware balancing.
- Attribute-driven calculations for health, damage, armour, and cooldowns.
- Custom menus and UI designed around the game's Japanese-fantasy direction.
- Playtesting and iteration on gameplay, presentation, and balance.

## Run the game

### Requirements

- Windows x64
- A machine capable of running an Unreal Engine 5 packaged game

### Steps

1. Download or clone this repository.
2. Open the `Cat Samurai Whiskers of War` folder.
3. Run `Cat Samurai Whiskers of War.exe`.

> Windows may show a security warning for unsigned downloadable executables. Only run files you trust.
